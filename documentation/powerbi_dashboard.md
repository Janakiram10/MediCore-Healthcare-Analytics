## Design
The PBIP page has been arranged programmatically into a two-row KPI band followed by a two-row analytical chart grid on a 1920×1080 page. The project uses the existing Power BI visuals rather than adding unnecessary pages or visuals.

## Important
The editable PBIP report is the source of truth for report-definition changes. The included `.pbix` is retained as the previously exported binary file and is not rewritten by this packaging script.
